## Запуск
Нужен Python 3.12+ с Tkinter и графическая сессия. В Windows Tkinter
включён в стандартный установщик Python. В Linux может потребоваться
системный пакет `python3-tk`. Внешних Python-зависимостей нет.
В каталоге репозитория запустите нужную программу:

```console
python notebook_demo.py
python menu_demo.py
python hello_demo.py
python currency_converter.py
python multiple_windows.py
```

Каждая команда открывает отдельную программу; для перехода к следующей
закройте текущее окно. В программе нескольких окон кнопку можно нажимать
повторно; закрытие главного окна закрывает дочерние.

Конвертер использует **фиксированные учебные курсы**: USD = 90 RUB,
EUR = 100 RUB. Это не текущие котировки. Сумма от 0 до 10¹²,
разделитель — точка или запятая; результат округляется до копеек
по правилу Decimal ROUND_HALF_EVEN.

## Проверки
```console
python -m unittest discover -v
```
Проверяются конвертация и ошибки ввода, переключение вкладок, кнопка,
меню Exit и независимое закрытие окон. GUI-тестам нужен доступ к экрану.
